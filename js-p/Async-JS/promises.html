🎯 JavaScript Promises Exercise

Exercise 1: Creating a Promise

Create a promise that resolves after a delay.

const promise = new Promise((resolve, reject) => {
  setTimeout(() => {
    resolve('Success!');
  }, 1000);
});

console.log('Promise created:', promise);
console.log('Is resolved:', promise instanceof Promise);
Output: Promise created

Exercise 2: Promise.then() - Success Handler

Handle the resolved value of a promise.

const promise = new Promise((resolve, reject) => {
  setTimeout(() => {
    resolve('Hello from Promise');
  }, 1000);
});

promise.then(value => {
  console.log('Resolved value:', value);
});

console.log('Promise created');
