🔐 What is a Closure?

A closure is a function that remembers and has access to variables from its outer function's scope, even after the outer function has finished executing.

Key Characteristics:
1. Inner function has access to outer function's variables
2. Inner function is returned from outer function
3. Inner function still has access to outer variables after outer function returns

Closures are created when:
1. A function is defined inside another function
2. An inner function is returned from the outer function
3. An inner function is assigned to a variable
