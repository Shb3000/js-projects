🎯 Understanding this

The keyword this refers to the object that called the function. Its value depends on how the function is invoked:

  • Global scope: this refers to window object
  • Regular function: this refers to the object that called it
  • Object method: this refers to the object
  • Arrow function: this inherits from enclosing function (cannot be changed)
  • Constructor: this refers to the new object being created
  • Class method: this refers to the instance
  • Event handler: this refers to the element that triggered the event
