📚 What is Hoisting?

Hoisting is a JavaScript mechanism where variable and function declarations are moved to the top of their scope before any code is executed. This happens automatically by the JavaScript engine.

Important Rules:
var - Hoisted and initialized with undefined
let - Hoisted but not initialized (Temporal Dead Zone - TDZ)
const - Hoisted but not initialized (TDZ)
Function declarations - Fully hoisted (can be called before declaration)
Function expressions - Not hoisted (cannot be called before assignment)
