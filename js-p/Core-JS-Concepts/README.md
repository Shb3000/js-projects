# Core JavaScript Concepts Exercises

This folder contains HTML exercises covering fundamental JavaScript concepts. Each exercise is self-contained and demonstrates a specific concept with executable code.

## Exercises

### 1. Arrow Functions (`arrow-functions.html`)
Learn about arrow functions and how they work with callbacks:
- Basic arrow function syntax
- Arrow functions as callbacks
- Arrow functions with parameters
- Arrow functions with default values
- Understanding `this` in arrow functions
- Arrow functions in reduce, map, filter

### 2. Higher-Order Functions & Callbacks (`higher-order-functions.html`)
Understand how functions can operate on other functions:
- What are higher-order functions?
- Callback functions explained
- Common HOFs: `map`, `filter`, `reduce`
- Function composition
- `Array.prototype.forEach`

### 3. Hoisting (`hoisting.html`)
Explore how JavaScript handles variable and function declarations:
- Variable hoisting basics
- Function hoisting
- `var`, `let`, and `const` hoisting
- Temporal dead zone (TDZ)
- Understanding `undefined` vs `ReferenceError`
- Best practices to avoid hoisting issues

### 4. Closures (`closures.html`)
Master the concept of closures:
- What is a closure?
- Inner and outer scopes
- Capturing variables
- Practical closure examples
- Closures in event handlers
- Closures with timers

### 5. The `this` Keyword (`this-keyword.html`)
Understand how `this` works in different contexts:
- `this` in global scope
- `this` in regular functions
- `this` in object methods
- `this` in arrow functions
- `this` in constructors
- `this` in classes
- `this` in event handlers
- Using `call()`, `apply()`, `bind()` to change `this`

### 6. Prototypes & Prototypal Inheritance (`prototypes.html`)
Learn about JavaScript's prototype-based inheritance:
- Prototypes and prototype chain
- `__proto__` vs `prototype`
- Constructor functions
- `Object.create()`
- ES6 classes
- Inheritance in classes
- `extends` keyword

## How to Use

1. Open any `.html` file in your browser
2. Read the code comments and exercise descriptions
3. Execute the code to see the output
4. Modify the code to practice different scenarios

## Tips

- Each exercise includes a hint section with guidance
- The output is displayed in a code block at the bottom of each exercise
- Code examples are clean and beginner-friendly
- All exercises run directly in the browser without a build step
