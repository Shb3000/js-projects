🔧 Understanding the Methods

Function.call(thisArg, ...args)
Executes the function immediately with this set to thisArg and arguments provided individually.

Function.apply(thisArg, [argsArray])
Executes the function immediately with this set to thisArg and arguments provided as an array.

Function.bind(thisArg, ...args)
Returns a new function with this permanently set to thisArg and arguments pre-bound.
