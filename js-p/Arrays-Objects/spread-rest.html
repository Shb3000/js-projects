Exercise 1: Spread Operator with Arrays

Use the spread operator to concatenate two arrays.

const arr1 = [1, 2, 3];
const arr2 = [4, 5, 6];
const combined = [...arr1, ...arr2];

Exercise 2: Merge Two Objects

Use the spread operator to merge two objects into one.

const obj1 = { name: 'Alice', age: 25 };
const obj2 = { city: 'NYC', country: 'USA' };
const merged = { ...obj1, ...obj2 };
Output: Name = , Age = , City = , Country =

Exercise 3: Rest Parameter with Array Concatenation

Use rest parameters to concatenate multiple arrays passed as function arguments.

function combine(...arrays) {
  return arrays.flat();
}
Output: combine([1,2], [3,4], [5,6]) =

Exercise 4: Copy Array with Spread

Create a copy of an array using the spread operator.

const original = [10, 20, 30];
const copy = [...original];
copy[0] = 999;
Output: Original[0] = , Copy[0] =

Exercise 5: Rest Parameter with Function

Use rest parameters to collect remaining function arguments.

function multiply(numbers) {
  let result = 1;
  for (let num of numbers) {
    result *= num;
  }
  return result;
}
Output: multiply(2, 3, 4) =

Exercise 9: Rest Parameter with Default

Use rest parameters with default values.

function sum(a = 0, b = 0, ...rest) {
  return a + b + rest.reduce((sum, val) => sum + val, 0);
}
Output: sum(10, 20) = , sum(1, 2, 3, 4) =
