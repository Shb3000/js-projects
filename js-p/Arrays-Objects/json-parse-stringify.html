🔧 Understanding JSON

JSON.stringify(): Converts a JavaScript object to a JSON string
JSON.parse():: Parses a JSON string back to a JavaScript object

  • JSON supports: strings, numbers, booleans, null, arrays, and objects
  • JSON does NOT support: functions, dates, undefined, symbols, Map, Set
  • Useful for: storing data in localStorage, sending data via HTTP
