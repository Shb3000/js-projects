# Arrays & Objects JavaScript Exercises

This folder contains HTML exercises covering JavaScript Arrays and Objects concepts. Each exercise is self-contained and demonstrates a specific concept with executable code.

## Exercises

### 1. Destructuring (`destructuring.html`)
Learn how to extract values from objects and arrays using destructuring syntax. Topics include:
- Basic variable destructuring from objects
- Multiple variable destructuring from arrays
- Default values for missing properties
- Nested object destructuring
- Spread operator in function calls
- Copying objects with spread
- Destructuring function parameters
- Rest parameters

### 2. Spread & Rest Operator (`spread-rest.html`)
Understand the spread (`...`) and rest (`...`) operators:
- Concatenating arrays with spread
- Merging objects with spread
- Rest parameters for collecting arguments
- Copying arrays and objects
- Combining spread and rest operators

### 3. JSON (`json.html`)
Master JSON manipulation in JavaScript:
- Stringifying objects to JSON
- Parsing JSON strings to objects
- Pretty-printing JSON with indentation
- Using reviver functions to transform data
- Using replacer functions to exclude properties
- Handling circular references
- Creating deep copies with JSON

### 4. Array Methods (`array-methods.html`)
Practice common array methods:
- `forEach()` - Iteration without mutation
- `map()` - Transform elements
- `filter()` - Select elements
- `find()` - Find first match
- `some()` - Check if any match
- `every()` - Check if all match
- `reduce()` - Aggregate values (sum, product)
- `sort()` - Sort elements
- `flatMap()` - Flatten and transform
- Object methods: `keys()`, `values()`, `entries()`, `fromEntries()`

## How to Use

1. Open any `.html` file in your browser
2. Read the code comments and exercise descriptions
3. Execute the code to see the output
4. Modify the code to practice different scenarios

## Tips

- Each exercise includes a hint section with guidance
- The output is displayed in a code block at the bottom of each exercise
