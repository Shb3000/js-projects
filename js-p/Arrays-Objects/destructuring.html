🔧 What is Destructuring?

Destructuring is a JavaScript feature that lets you unpack values from arrays or properties from objects into separate variables. It makes your code cleaner and more readable.

  • Array destructuring: [a, b, c] = [1, 2, 3] sets a=1, b=2, c=3
  • Object destructuring: {a, b} = {a: 1, b: 2} sets a=1, b=2
  • Nested destructuring: Extract values from nested objects/arrays
  • Default values: Provide fallback when a value is missing
  • Renaming: Use alias to rename the extracted variable

🏪 Real-Life Example: Restaurant Ordering System

Imagine a restaurant's order-taking system. When a server receives an order from a customer, they might order multiple dishes. Using destructuring makes it easy to extract individual items from the order array.

// Restaurant Order Example const order = { restaurant: "Burger King", order: [ { name: "Big Mac", price: 5.99, qty: 2 }, { name: "Fries", price: 2.49, qty: 1 }, { name: "Coke", price: 1.99, qty: 2 } ] }; // Destructure the order data const { restaurant, order: dishes } = order; const [firstDish, secondDish, thirdDish] = dishes; console.log(restaurant); // "Burger King" console.log(firstDish.name); // "Big Mac" console.log(thirdDish.name); // "Coke"

Why use it? When you're working with restaurant orders from multiple tables, you often need to extract specific pieces of information. Destructuring lets you do this cleanly without creating multiple temporary variables.
