🔧 Understanding Spread and Rest

Spread operator (...): Expands an array/object into individual elements
Rest operator (...): Collects individual elements into an array/object

  • Spread in function: func(a, b, c) becomes func(...arr)
  • Rest in function: function(a, ...rest) collects remaining arguments
  • Spread in array: [...arr1, ...arr2] combines arrays
  • Rest in object: {...obj1, ...obj2} merges objects
  • Spread in object: {key1, ...obj, key2} adds properties
