🔧 Understanding the Event Loop

Call Stack: Executes synchronous code top-down
Event Queue: Stores async operations (setTimeout, events)
Microtask Queue: Higher priority (Promise.resolve, MutationObserver)
Macrotask Queue: Lower priority (setTimeout, setInterval, I/O)

  • JavaScript is single-threaded
  • Event loop continuously checks queues when call stack is empty
  • Microtasks execute before macrotasks in the same event
