🚫 JavaScript Non-blocking Behavior Exercise

Exercise 1: Blocking vs Non-blocking Code

Understand the difference between blocking and non-blocking operations.

console.log('1. Start');
const start = Date.now();

// Blocking operation (synchronous)
for (let i = 0; i < 1000000; i++) {
  // do nothing
}

const end = Date.now();
console.log('2. After blocking loop (duration: ' + (end - start) + 'ms)');

console.log('3. After non-blocking code');
Output:

Duration: ms

Hint: Blocking code stops execution until it completes. Non-blocking code returns immediately.

Exercise 2: setTimeout is Non-blocking

setTimeout doesn't block execution - it schedules a callback to run later.

console.log('1. Before setTimeout');

const start = Date.now();
setTimeout(() => {
  console.log('2. Inside setTimeout');
}, 100);

const end = Date.now();
console.log('3. After setTimeout (duration: ' + (end - start) + 'ms)');

setTimeout(() => {
  console.log('4. Second setTimeout');
}, 100);
Output:

Duration: ms

Exercise 3: Non-blocking I/O with Promises

Use promises to handle non-blocking operations.

console.log('1. Before promise');

const start = Date.now();

const delay = (ms) => new Promise(resolve => setTimeout(resolve, ms));

const result = await delay(100);

const end = Date.now();
console.log('2. After delay (duration: ' + (end - start) + 'ms)');

console.log('3. After promise resolves');

Duration: ms

    Exercise 5: Non-blocking API Simulation

    Simulate non-blocking I/O operations.

    console.log('1. Request sent');

// Simulate fetch-like operation
const simulateFetch = (url) => {
  return new Promise((resolve, reject) => {
    setTimeout(() => {
      console.log('3. Fetch completed');
      resolve({ status: 'success', url: url });
    }, 1000);
  });
};

// Start the "fetch" without blocking
const start = Date.now();
simulateFetch('https://example.com').then(() => {
  const end = Date.now();
  console.log('4. After fetch (duration: ' + (end - start) + 'ms)');
});

console.log('2. Continue after request');

setTimeout(() => {
  console.log('5. Later task');
}, 500);

          Exercise 8: Non-blocking with setInterval

          SetInterval schedules repeated non-blocking callbacks.

          console.log('1. Interval started');

let count = 0;

const intervalId = setInterval(() => {
  count++;
  if (count < 3) {
    console.log('3. Interval callback #' + count);
  } else {
    console.log('4. Interval completed');
    clearInterval(intervalId);
  }
}, 100);

console.log('2. After starting interval');

setTimeout(() => {
  console.log('5. After interval finishes');
}, 500);
