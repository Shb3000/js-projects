🔧 JavaScript Enhanced Object Literals Exercise

Exercise 1: Short Property Syntax

Use the short property syntax for object properties.

const person1 = {
  name: 'Alice',
  age: 25
};

const person2 = {
  name: 'Bob',
  age: 30
};

console.log('Person 1:', person1.name);
console.log('Person 2:', person2.age);
Output:

Person 1: , Person 2:

Exercise 2: Computed Property Names

Use computed property names with brackets.

const keys = ['name', 'age'];
const object = {
  [keys[0]]: 'Charlie',
  [keys[1]]: 35
};

console.log('Name:', object.name);
console.log('Age:', object.age);
Output:

Name: , Age:

Exercise 3: Object Spread

Use the spread operator to copy object properties.

const base = {
  name: 'David',
  age: 28
};

const extended = {
  ...base,
  city: 'NYC'
};

console.log('Extended:', extended.name, extended.age, extended.city);
Output:

Extended: , ,

Exercise 4: Method Shorthand

Use method shorthand for object methods.

const calculator = {
  add(a, b) {
    return a + b;
  },
  subtract(a, b) {
    return a - b;
  }
};

console.log('Add:', calculator.add(5, 3));
console.log('Subtract:', calculator.subtract(5, 3));
Output:

Add: , Subtract:

Exercise 5: Getter/Setter Shorthand

Use getter and setter shorthand.

const counter = {
  value: 0,
  get getValue() {
    return this.value;
  },
  setValue(newValue) {
    this.value = newValue;
  }
};

console.log('Initial:', counter.getValue);
counter.setValue(10);
console.log('After:', counter.getValue);
Output:

Initial: , After:

Exercise 7: Object Destructuring in Property Shorthand

Use destructuring in property shorthand.

const options = {
  name: 'Frank',
  age: 40,
  gender: 'Male'
};

const person = {
  ...options,
  ...{
    city: 'LA'
  }
};

console.log('Person:', person.name, person.age, person.city);
Output:

Person: , ,

Exercise 8: Static Method

Use static method in object literal.

const Math = {
  PI: 3.14159,
  isPrime(n) {
    return n % 2 !== 0;
  }
};

console.log('PI:', Math.PI);
console.log('5 is prime:', Math.isPrime(5));
Output:

PI: , 5 is prime:

Exercise 9: Object Literal with Computed Methods

Use computed method names.

const methodNames = ['multiply', 'divide'];
const math = {
  [methodNames[0]](a, b) {
    return a * b;
  },
  [methodNames[1]](a, b) {
    return a / b;
  }
};

console.log('Multiply:', math.multiply(4, 5));
console.log('Divide:', math.divide(10, 2));
Output:

Multiply: , Divide:
