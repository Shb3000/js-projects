📝 JavaScript Template Literals Exercise

Exercise 1: Basic Template Literal

Use backticks to create a template literal with variables.

const name = 'Alice';
const age = 25;

const message = \`Hello, \${name}! You are \${age} years old.\`;
console.log(message);
Output:

Hello, Alice! You are 25 years old.

Exercise 2: Multiple Expressions

Use multiple expressions in a template literal.

const first = 'Alice';
const last = 'Smith';
const year = 2024;

const bio = \`Name: \${first} \${last}
Born: 1999
Year: \${year}\`;
console.log(bio);
Output:

Name: \${last} Born: 1999 Year: 2024

Exercise 3: Newlines in Template Literal

Create multi-line strings with backticks.

const greeting = \`Hello, world!
This is a
multi-line string.\`;
console.log(greeting);
Output:

Hello, world! This is a multi-line string.

Exercise 4: Interpolation

Use backticks for variable interpolation.

const count = 5;
const item = 'apple';

const list = \`1. \${item}
2. \${item}
3. \${item}
4. \${item}
5. \${item}\`;
console.log(list);
Output:

1. 2. 3. 4. 5.

Exercise 5: Escape Characters

Use escape characters in template literals.

const text = \`Hello\
World!

This has
multiple newlines.\`;
console.log(text);
Output:

Hello\ World! This has multiple newlines.

Exercise 6: String Concatenation vs Template

Compare string concatenation with template literals.

const name = 'Alice';
const age = 25;

// String concatenation
const concat = 'Hello, ' + name + '! You are ' + age + ' years old.';

// Template literal
const template = \`Hello, \${name}! You are \${age} years old.\`;

console.log('Concat:', concat);
console.log('Template:', template);
Output:

Concat: Hello, Alice! You are 25 years old. Template: Hello, Alice! You are 25 years old.

Exercise 7: Template with Math

Use template literals with mathematical expressions.

const a = 10;
const b = 5;

const sum = \`Sum: \${a + b}\`;
const product = \`Product: \${a * b}\`;
const quotient = \`Quotient: \${(a + b) / 2}\`;

console.log(sum);
console.log(product);
console.log(quotient);
Output:

Sum: Product: Quotient:

Exercise 8: Template with Objects

Use template literals with object properties.

const person = {
  name: 'Bob',
  age: 30
};

const intro = \`Hi, I'm \${person.name}.
I'm \${person.age} years old.\`;
console.log(intro);
Output:

Hi, I'm . I'm years old.

Exercise 9: Template Trailing Comma

Create objects with trailing commas in templates.

const items = \`\${[1, 2, 3]} is my favorite list.\`;
console.log(items);
Output:

1, 2, 3 is my favorite list.
