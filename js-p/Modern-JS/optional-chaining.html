🔗 JavaScript Optional Chaining Exercise

Exercise 1: Basic Optional Chaining

Use optional chaining to safely access nested properties.

const user = {
  name: 'Alice',
  address: {
    city: 'NYC',
    country: 'USA'
  }
};

const city = user.address?.city;
console.log('City:', city);
Output:

City:

Exercise 2: Optional Chaining with Null Object

Use optional chaining with a null object.

const user = null;
const city = user?.address?.city;
console.log('City:', city);
Output:

City:

Exercise 3: Optional Chaining with Undefined

Use optional chaining with undefined properties.

const user = {
  name: 'Bob'
};

const city = user.address?.city;
const country = user.address?.country;
console.log('City:', city);
console.log('Country:', country);
Output:

City: , Country:

Exercise 4: Optional Chaining with Default Value

Use optional chaining with a default value.

const user = null;
const city = user?.address?.city ?? 'Unknown';
console.log('City:', city);
Output:

City:

Exercise 5: Optional Chaining with Nullish Coalescing

Use nullish coalescing with optional chaining.

const data = {
  name: 'Charlie',
  age: null,
  email: undefined
};

const age = data.age ?? 0;
const email = data.email || 'no-email';
console.log('Age:', age);
console.log('Email:', email);
Output:

Age: , Email:

Exercise 6: Optional Chaining with Nested Objects

Use optional chaining with deeply nested objects.

const user = {
  profile: {
    bio: 'Developer',
    social: {
      twitter: '@dev',
      github: null
    }
  }
};

const twitter = user.profile?.social?.twitter;
const github = user.profile?.social?.github ?? 'no-github';
console.log('Twitter:', twitter);
console.log('GitHub:', github);
Output:

Twitter: , GitHub:

Exercise 7: Optional Chaining with Array

Use optional chaining with arrays and object properties.

const user = {
  profile: {
    social: null
  }
};

const twitter = user.profile?.social?.twitter ?? 'no-twitter';
console.log('Twitter:', twitter);
Output:

Twitter:

Exercise 8: Optional Chaining vs Traditional Access

Compare optional chaining with traditional property access.

const user = {
  profile: {
    bio: 'Tester'
  }
};

// Traditional access (would throw error)
// const bio = user.profile.bio;

// Optional chaining (returns undefined)
const bio1 = user.profile?.bio;

// Optional chaining with default
const bio2 = user.profile?.bio ?? 'no-bio';

console.log('Bio with chaining:', bio1);
console.log('Bio with default:', bio2);
Output:

Bio with chaining: , Bio with default:

Exercise 9: Optional Chaining in Function Call

Use optional chaining in function calls.

const user = {
  name: 'Eve',
  social: null
};

const greet = user?.social?.twitter ?? 'no-social';
console.log('Greeting:', 'Hi ' + user.name + '! Follow me at ' + greet);
Output:

Greeting:

Exercise 10: Optional Chaining with Method Call

Use optional chaining with method calls.

const user = {
  profile: {
    bio: 'Writer'
  }
};

const bio = user.profile?.bio;
const bioLength = bio?.length ?? 0;
console.log('Bio:', bio);
console.log('Length:', bioLength);
Output:

Bio: , Length:
