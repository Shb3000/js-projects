📦 JavaScript ES Modules Exercise

Exercise 1: Import and Export

Basic import and export syntax in ES modules.

// module1.js
export const name = 'Alice';
export const age = 25;

// main.js
import { name, age } from './module1.js';
console.log('Name:', name);
console.log('Age:', age);
Output:

Name: , Age:

Exercise 2: Default Export

Use default export for a single value.

// module2.js
export default function greet(name) {
  return 'Hello, ' + name + '!';
}

// main.js
import greet from './module2.js';
const message = greet('Bob');
console.log('Message:', message);
Output:

Message:

Exercise 3: Namespace Export

Use namespace export for multiple values.

// module3.js
export const user = {
  name: 'Charlie',
  age: 30
};

export const email = 'charlie@example.com';

// main.js
import { user, email } from './module3.js';
console.log('User:', user.name);
console.log('Email:', email);
Output:

User: , Email:

Exercise 4: Import with Alias

Import with a custom alias.

// module4.js
export const value = 42;

// main.js
import { value as myValue } from './module4.js';
console.log('My value:', myValue);
Output:

My value:

Exercise 5: Wildcard Import

Import everything from a module.

// module5.js
export const x = 1;
export const y = 2;
export const z = 3;

// main.js
import * as module5 from './module5.js';
console.log('X:', module5.x);
console.log('Y:', module5.y);
console.log('Z:', module5.z);
Output:

X: , Y: , Z:

Import and re-export from a module.

Exercise 7: Multiple Imports

Import multiple modules in one file.

import { name } from './module1.js';
import { greet } from './module2.js';
import { value } from './module4.js';

console.log('Name:', name);
console.log('Greeting:', greet('David'));
console.log('Value:', value);
Output:

Name: , Greeting: , Value:

Exercise 8: Dynamic Import

Use dynamic import to load modules on demand.

import('./module4.js')
  .then(module => {
    console.log('Value:', module.value);
  });
Output:

Value:

Exercise 9: Module with Conditionals

Create a module with conditional exports.

// module9.js
export function add(a, b) {
  return a + b;
}

// main.js
import { add } from './module9.js';
console.log('Sum:', add(5, 3));
Output:

Sum:

Exercise 10: Module with Async

Export an async function from a module.

// module10.js
export async function fetchData() {
  return new Promise(resolve => {
    setTimeout(() => resolve('Data fetched'), 1000);
  });
}

// main.js
import { fetchData } from './module10.js';
fetchData().then(data => console.log('Data:', data));
Output:

Data:
