⚖️ JavaScript Nullish Coalescing Exercise

Exercise 1: Basic Nullish Coalescing

Use the nullish coalescing operator (??) to provide a default for null or undefined.

const value = null;
const result = value ?? 'default';
console.log('Result:', result);
Output:

Result:

Exercise 2: Nullish Coalescing with Undefined

Use ?? with undefined values.

const value = undefined;
const result = value ?? 'default';
console.log('Result:', result);
Output:

Result:

Exercise 3: Nullish Coalescing with Falsy Values

Understand that ?? only skips null and undefined, not other falsy values.

const value = 0;
const result = value ?? 'default';
console.log('Result:', result);
Output:

Result:

Exercise 4: Nullish Coalescing with False

Output:

Result:

Exercise 5: Nullish Coalescing with Empty String

Use ?? with empty string.

const value = '';

Exercise 6: Nullish Coalescing Comparison

Compare ?? with || operator.

const value = null;
const result1 = value || 'default';
const result2 = value ?? 'default';

console.log('|| Result:', result1);
console.log('?? Result:', result2);
Output:

|| Result: , ?? Result:

Exercise 7: Nullish Coalescing in Object Property

Use ?? with object properties.

const user = {
  name: 'Alice',
  age: null
};

const age = user.age ?? 0;
console.log('Age:', age);
Output:

Age:

Exercise 8: Nullish Coalescing with Nested Object

Use ?? with nested object properties.

const user = {
  profile: {
    bio: null,
    age: 25
  }
};

const bio = user.profile?.bio ?? 'No bio';
const age = user.profile?.age ?? 0;
console.log('Bio:', bio);
console.log('Age:', age);
Output:

Bio: , Age:

Exercise 9: Nullish Coalescing with Default

Use ?? with a more complex default value.

const config = {
  apiUrl: null,
  timeout: 5000
};

const apiUrl = config.apiUrl ?? 'https://api.example.com';
console.log('API URL:', apiUrl);
Output:

API URL:

const value = false;
const result = value || 0 ?? 'default';
